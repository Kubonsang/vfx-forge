# Basic Recipe Sample

1. Import this sample from Package Manager.
2. Register an `impact_heavy` template in the Template Catalog.
3. Ensure the template exposes properties matching its bindings.
4. Open `Tools > VFX Forge > Open Window`.
5. Select the imported JSON and Catalog.
6. Validate before compiling.

The starter package does not include an authored VFX Graph or Prefab because project style and Render Pipeline settings must be owned by the host project.
